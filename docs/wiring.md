# 配線

## 確定した接続

| 項目 | 値 |
|---|---|
| ESP32-C5 モジュール | ESP32-C5-WROOM-1 |
| CAN TX(ESP→トランシーバーTXD) | GPIO23 |
| CAN RX(トランシーバーRXD→ESP) | GPIO24 |
| CANトランシーバー | WCMCU-1051(TJA1051T/3) |
| CAN | Classic CAN 1Mbps、C620 ×4 |
| C620 ID と位置 | 前左=ID3、前右=ID1、後左=ID2、後右=ID4(上から見て前が上) |
| 車体 | 中心から各輪まで0.25m、車輪半径0.05m(直径100mm)、減速比19、駆動方向は接線 |

これらは `platform/control/vehicle_config.hpp` に定義しています(取り付け符号は実機確認後に更新)。

WCMCU-1051の電源(VCC/VIO)、`S` ピンの扱い、終端抵抗の有無は、モジュールの資料で確認してください。ESPのGNDとC620側のGNDは共通にします。

実機試験の初期に、送信がエラーになる(bit error、bus off)状態がありました。配線を直して解消しましたが、原因の特定(TX/RXの取り違え、電源、接触不良など)は記録していません。同じ症状が出たときは、[ベンチ試験](bench.md) の `esp32c5_can_selftest` で、C620なしで経路を切り分けてください。

## 未確定

Piの型番、物理インターロックのGPIO(`kInterlockGpio`、現在は未配線)、給電方法、バス終端と配線長は未確定または未検証です。`platform/config.example.json` は未設定項目のスキーマ例でファームウェアは読みません。

接続の責務は ESP32-C5 TWAI TX/RX → 外付けCANトランシーバー → CAN_H/CAN_L → C620 ×4 です。Classic CAN 1Mbps。3.3Vロジックへの適合、GND基準、絶縁/電源、終端抵抗、配線長・分岐長は採用部品の資料に基づき確認してください。モーター電源をC5のGPIOから直接供給しません。

C620はID1..4を重複なく設定します。フィードバック0x201..0x204とmotor_index 0..3を対応させます。電流指令0x200は各IDの順に符号付き16bit big endianを4つ格納します。feedbackのRPMはモーター軸RPMです。

実機試験ではまず駆動電源を切ってロジック・CAN受信を確認し、車輪を安全に浮かせた状態で各車輪のID/回転方向/取り付け符号を記録してください。テストコードの配置・ギヤ比・車輪径・符号は架空の計算例で、転用しないでください。

物理非常停止は駆動電源を遮断する独立回路が必要です。ソフトウェアゼロ電流はCAN故障、ESP停止、電源断時には到達を保証できません。部品確定後、遮断回路と再起動インターロックを回路図と実測で検証するまでは走行を許可しません。
