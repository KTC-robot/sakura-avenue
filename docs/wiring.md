# 配線準備（GPIO未確定）

現時点では具体的なPi/ESP32-C5ボード、GPIO、トランシーバー型番、給電方法を確定しません。`firmware/config.example.json` は未設定の一覧であり実機設定ではありません。

接続の責務は ESP32-C5 TWAI TX/RX → 外付けCANトランシーバー → CAN_H/CAN_L → C620 ×4 です。Classic CAN 1Mbps。3.3Vロジックへの適合、GND基準、絶縁/電源、終端抵抗、配線長・分岐長は採用部品の資料に基づき確認してください。モーター電源をC5のGPIOから直接供給しません。

C620はID1..4を重複なく設定します。フィードバック0x201..0x204とmotor_index 0..3を対応させます。電流指令0x200は各IDの順に符号付き16bit big endianを4つ格納します。feedbackのRPMはモーター軸RPMです。

実機試験ではまず駆動電源を切ってロジック・CAN受信を確認し、車輪を安全に浮かせた状態で各車輪のID/回転方向/取り付け符号を記録してください。テストコードの配置・ギヤ比・車輪径・符号は架空の計算例で、転用しないでください。

物理非常停止は駆動電源を遮断する独立回路が必要です。ソフトウェアゼロ電流はCAN故障、ESP停止、電源断時には到達を保証できません。部品確定後、遮断回路と再起動インターロックを回路図と実測で検証するまでは走行を許可しません。
